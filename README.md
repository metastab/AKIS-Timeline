# AKIS Utilities Hub

A centralized collection of management, tracking, and showcase utilities for our ongoing game project, **AKIS**.

---

## Overview

This repository (`utils_AKIS-tracker`) serves as the primary home for internal tools supporting the development of the **AKIS** game project. 

All projects located in the subsequent subdirectories are dedicated utilities built for project management, systems tracking, and/or showcase presentations. Maintaining these tools in a modular structure keeps our development pipeline organized without cluttering the core game repository.

---

## Utilities Breakdown

| Utility Directory | Category | Purpose |
| :--- | :--- | :--- |
| [`AKIS-tracking-utility`](./AKIS-tracking-utility/) | Management & Tracking | Real-time CRUD checklist and systems tracker monitoring development status and feature priorities across core gameplay systems (Interaction, Inventory, Enemy AI, Locomotion, Camera, Props, Character). |
| [`AKIS-timeline-utility`](./AKIS-timeline-utility/) | Management & Showcase | Timeline and milestone tracking utility designed to map out production roadmaps, development history, and schedule progress. |

---

## Structure & Guidelines

- **Self-Contained Projects**: Each subfolder is an independent application with its own dependencies, configuration files, and scripts.
- **Individual Documentation**: Refer to the `README.md` within each subfolder for detailed instructions on local setup, environment variables, and tech stack specifications for that particular utility.
- **Unified Objective**: Every tool here exists to assist, monitor, or showcase work done on the **AKIS** game project.

---

## Game Project Context

**AKIS** is an ongoing game project. The utilities housed in this workspace are maintained by and for the dev team to support workflow automation, milestone tracking, and project visibility.
